Leonida Trophy Guide — the offline guide and tracker for all 55 Grand Theft Auto VI trophies on PS5: official names, descriptions and grades, a cited guide in our own words for every trophy, a six-stage roadmap to the platinum, the one possibly missable trophy flagged, and a checklist that saves in the browser with export/import, kind and grade filters, search, and a spoiler setting that hides the 28 hidden trophies until earned. Static files only, no build step, works with the network off.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
